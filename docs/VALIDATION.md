## 存储和基础功能

- 16 MiB Flash：8 MiB 应用分区，8128 KiB `j2me` FAT 分区（`0x810000`），启用磨损均衡。
- 用户提供的六个 JAR 共 5,189,962 字节；从生成的 FAT 镜像重新提取后，六项 SHA-256 均与原文件相同。游戏区烧录通过设备端校验。
- RGB LCD、GT1151 触摸控制器、ES8389 均成功初始化。多点触摸映射已实现；本次自动输入由串口注入，未将它表述为人工触屏测试。
- 内置 Java MIDlet 三轮各运行 90 帧，全部正常返回；每轮 PSRAM 均从 **13,711,732 字节回到 13,711,732 字节**，差值为零。
- FIRE 按下/松开分别到达 MIDlet 为 `-5`；数字 5 为 `53`；指针坐标 `(100,140)` 正确到达 Java 回调。
- 内置 RMS 启动计数连续为 3、4、5、6；此前两次记录在应用重新烧录后仍保留。
- 两次音调测试输出累计 17,280 个 48 kHz 双声道采样帧，codec 写入错误为 0。外部游戏也触发 22050 Hz 单声道 PCM，经重采样输出。
- 176×208、128×160、320×240、240×320 各运行内置演示 30 帧，均正常返回且 PSRAM 差值为零；最后恢复 240×320。
- 额外上传上游音频测试 JAR：9770 字节，CRC32 `44ded0c5`，设备返回 `PUT_OK`。测试覆盖 WAV、AMR、ADPCM 格式及 tone 生命周期，codec 写入错误为 0。该测试 MIDlet 不安装 Displayable，运行器以 `rc=1 / nothing to show` 返回，不能将它作为图形游戏启动失败。

以上证明驱动和数据通路工作；没有通过麦克风确认扬声器音质，也没有把帧缓冲截图当作屏幕实拍。

## 六款游戏

以下是有限时长、少量自动按键下的观察。每款都能加载、处理输入并退出；退出时 PSRAM 差值均为零，最终测试固件没有出现 MCU panic。**这不是通关或完整兼容性认证。**

| --- | --- |
| 都市赛车6火线追击 | 显示 Gameloft 启动标识；第一轮提交 32 帧后正常退出，未验证进入比赛 |
| 极品飞车14之热力追踪中文版 | 显示标题画面；第一轮提交 457 帧，触发 PCM 音频；未验证完整比赛 |

部分游戏会抛出并捕获 Java 异常，日志包括 RMS 尚不存在、空引用、资源加载和线程等待等。仅凭某条 `thrown` 日志不能断言游戏已失败；画面停留于启动或加载阶段，也不能断言可正常游玩。当前版本的限制需要结合上游兼容性和更长的实际游玩继续确认。

## 复现和证据

```sh
bash tools/idf.sh build
bash tools/idf.sh -p /dev/ttyUSB0 -b 2000000 app-flash
python3 tools/serial_console.py smoke
python3 tools/serial_console.py command list
python3 tools/serial_console.py command 'run 2'
python3 tools/serial_console.py shot build/game.png --game
python3 tools/serial_console.py command stop
```

本机 `build/verification` 保存 `smoke.log`、`games.log`、`game6.log`、`audio-upload.log`、`audio.log` 和各款游戏的帧缓冲截图。`games.log` 的批量主机进程在第五款期间被中止，板子继续正常运行；第五款的最终统计由随后单独发送 `stats` / `stop` 获取，第六款另存日志。因此不把批量主机脚本退出码当作六款全程自动测试通过的凭据。

开发中发现并修正了列表字体状态未初始化的问题；另外通过虚拟文件接口规避上游内存 JAR 借用路径在退出时释放静态数据的问题。最后的回归结果来自修正后的固件，子模块源码保持原样。

方向键界面更新：上下左右改为对应朝向的实心三角形，中间 FIRE 改为实心正方形。已重新编译、烧录并通过板上演示和帧缓冲截图检查（`build/verification/icons-lcd.png`）；演示退出后 PSRAM 差值为零。该应用二进制 SHA-256 为 `8e80877f166fd7355b484c3b040e72661826cc1d375855630045e3cc14d205fa`。

后续性能和音频优化已烧录并完成新一轮实机回归，当前应用 SHA-256 为 `2e99403fc6a296a3ab5940670c6034423bc766408a393378129122c7f50d6e35`。固定计算耗时降低 38.0%，连续重绘从 28.3 提升到 30.0 FPS；WAV/MIDI 完整播放，测试期间音频欠载和 codec 写入错误均为零。三轮内置演示、四种分辨率、六款游戏启动/退出及有效按键脚本均通过；PSRAM 每次恢复为 13733944 字节。详细条件、结果及兼容性边界见 [性能记录](PERFORMANCE.md)。
