# 仙剑奇侠传 2008 声音设置页缺字（2026-11-11）

原始 JAR 为 `仙剑奇侠传(2008)_12406.jar`，711,995 字节，SHA-256 见 [字体检查](updates/2026-11-11-pal2008/font-validation.json)。本次只更新板级字体及其生成脚本，nano_j2me 核心继续使用 `a2e5ba8`，游戏 JAR 保持原样。

## 原因与操作

游戏使用 Nokia FullCanvas 自绘界面，提示内容为繁体中文 `音樂開關: 開啟/關閉`，底部为 `切換` 和 `確認`。原字体仅覆盖 GB2312，缺少 `樂開關啟閉換確認` 等字，画面因此只留下“音”、冒号和“切”，右下角的确认按钮完全不可见。这是字形缺失，界面仍在运行。

该页面的游戏逻辑使用左软键（模拟器的 **SOFT L**）切换声音，右软键（**SOFT R**）确认并继续；中间确认键和数字 5 不能替代这一页的右软键。修复前实测右软键已经可以离开提示页，因此保留游戏原有按键语义。

修复前的 [提示页](updates/2026-11-11-pal2008/initial.png) 和 [右软键确认后的画面](updates/2026-11-11-pal2008/before-softr.png) 保留在记录目录。

## 字体与容量

字体加入 Big5 符号及第一字集常用繁体字（截至 C67E），从 7,619 增至 9,833 个 Unicode 字符。原有字符全部保留，advance、行高和基线没有变化。检查了 JAR 全部 3 个 class：代码常量包含 257 个不同汉字，原来缺失 102 个，更新后缺失为 0。此检查覆盖代码中的文字，不等同于验证游戏全流程的外部资源文本。

为容纳字体，生成时去除 CFF hint 指令，保留轮廓与度量，由 FreeType 继续进行灰度栅格化。字体大小 2,159,008 字节，比原来增加 327,368 字节。完整应用为 8,273,680 字节，现有 8 MiB 应用分区剩余 114,928 字节；没有扩大分区或删除 Flash 游戏。Big5 第二字集的生僻字仍不在本字体范围内。

构建身份见 [固件记录](updates/2026-11-11-pal2008/firmware.json)。

## 实机验证

应用已通过 `/dev/ttyUSB1` 烧录并校验 Flash 哈希；只写应用，不写 FAT 分区。使用独立临时 RMS 分别测试声音开启和关闭，两次均能确认、到达标题并进入主菜单。左软键切换前后文字和截图不同，再次切换后与默认画面一致。

- [开启提示](updates/2026-11-11-pal2008/prompt-default.png)、[关闭提示](updates/2026-11-11-pal2008/prompt-toggled.png)：提示和两侧软键文字完整显示。
- [标题](updates/2026-11-11-pal2008/after-confirm.png)、[主菜单](updates/2026-11-11-pal2008/menu.png)：繁体文字可见，两种声音设置都能到达同一主菜单。
- 两次退出均为 `rc=0`、`scale_mismatch=0`。第一次运行后常驻分配增加 532 字节，第二次退出 PSRAM 差值为 0；记录保留实际数据，不宣称每次退出均为零。
- LCD 90 帧检查 `mismatches=0`、`timeouts=0`，仍使用 RGB 双缓冲和 DMA2D。
- 保存的 240×320、MAX SIZE、音量 40、FPS/JIT 关闭、双核/SIMD/PPA 开启保持一致；没有删除游戏或用户存档。

详见 [设备验证数据](updates/2026-11-11-pal2008/device-validation.json)。测试限于提示、标题和主菜单，没有验证完整剧情流程。声音开启路径仍会记录原有的音乐资源解析 `MediaException`，游戏捕获后可继续；本次没有修复该资源的音乐解码，也没有把“开启”状态当作有声播放的证据。

最后已用正常 RMS 重新打开游戏，右软键确认后停在主菜单，见 [最终状态](updates/2026-11-11-pal2008/final-device.json) 和 [LCD 全屏截图](updates/2026-11-11-pal2008/final-lcd.png)。清理本轮字体容量试验、反汇编、临时脚本、Python 缓存及重复截图，共约 10.7 MiB；保留当前固件构建和有效验证记录，见 [清理明细](updates/2026-11-11-pal2008/cleanup.json)。
